# shinycapabilities 0.1.0

- Initial private alpha of the generic capability-oriented workflow framework.
- Added typed graph and port contracts, deterministic planning, caching,
  staleness, cancellation, proposals, composites, output placement, and
  workflow serialization.
- Added the React Flow widget with responsive capability palette, Shiny-owned
  inspector, accessible interaction, and bundled production assets.
- Added package architecture, security, contribution governance, and CI.
